Тесты протокола используют независимые опубликованные кадры Wiren Board, стандартный вектор CRC16/MODBUS и отдельные негативные сценарии. Проверяются неверные адрес/команда, CRC, недопустимый BCD, неполный ответ, шум и эхо.

## Воспроизведение

Из корня архива:

```bash
sh arduino/tests/run.sh
```

В `raspberry-pi/`:

```bash
mvn clean verify
```

На Linux с Java 17+ и Python 3, из корня архива:

```bash
python3 tests/serial_integration.py dist/mercury-pi.jar
```

Последняя проверка поднимает только loopback HTTP и временный псевдотерминал. Она не открывает настоящие `/dev/serial0` или GPIO и выдаёт только синтетический ответ. Не нужны внешние Python-пакеты.

## Что остаётся проверить на оборудовании

Нужно подтвердить маркировку именно вашего прибора, адрес и скорость порта, питание интерфейса, полярность проводов, устойчивость выбранной линии и совпадение T1/T2 с дисплеем. UART 9600 и физические схемы основаны на документации; их испытание на счётчике 2006 года не выполнялось. Исполняемый код готов для такого испытания, но сборка и имитация не являются подтверждением электрической совместимости конкретного экземпляра.
